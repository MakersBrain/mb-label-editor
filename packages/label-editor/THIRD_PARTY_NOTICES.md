# Third-party notices

This package uses Svelte and integrates `@makersbrain/printer-sdk`. Dependency
versions and publisher license metadata are recorded in the workspace lockfile.
Bundled public assets are original synthetic MakersBrain works with per-entry
provenance. No vendor APK-derived or proprietary catalogue asset is included.

`assets/fonts` carries static TrueType faces (regular and bold) so a label can
embed a printable face offline: IBM Plex Sans, IBM Plex Mono, Inter, Open Sans,
Lato, Montserrat, Oswald, Playfair Display, Merriweather and Source Code Pro
under the SIL Open Font License 1.1, and Roboto and Roboto Mono under the
Apache License 2.0. The files are the static instances served by Google Fonts.
`assets/fonts/bundled-fonts.json` records each file's family, weight, licence,
origin and SHA-256; keep this notice with them.
